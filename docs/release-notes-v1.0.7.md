## es

### Kitsu X 1.0.7

Esta versión mejora la actualización automática de la biblioteca y completa la compatibilidad con repositorios y extensiones de manga modernas.

### Cambios

- Los repositorios de anime y manga ahora se administran desde un único apartado de listados de extensiones.
- Se añadió compatibilidad con el índice moderno de Keiyoushi para mostrar, instalar y actualizar extensiones de manga.
- Las extensiones de manga instaladas desde otras aplicaciones compatibles vuelven a mostrarse junto con las disponibles.
- Las actualizaciones programadas de anime y manga ahora persisten en segundo plano, incluso con la aplicación cerrada o después de reiniciar el dispositivo.
- El intervalo predeterminado de actualización de biblioteca es de 12 horas y se añadieron opciones de 6, 8, 12, 24, 48, 72 horas y semanal.
- Las notificaciones de actualización muestran primero las obras con contenido nuevo, después las omitidas y finalmente las que produjeron errores.
- Home incorpora una bandeja de novedades agrupada en `Hoy`, `Ayer` y `Esta semana`, con acceso directo para reproducir o leer.
- Las extensiones pendientes pueden actualizarse con `Actualizar todas`, manteniendo la confirmación del usuario y la verificación de firmas.
- Se añadieron nuevos bugs para solucionar en versiones posteriores.

## en

### Kitsu X 1.0.7

This version improves automatic library updates and completes compatibility with modern manga repositories and extensions.

### Changes

- Anime and manga repositories are now managed from a single extension lists section.
- Added support for Keiyoushi's modern index to display, install, and update manga extensions.
- Manga extensions installed by other compatible applications are shown together with available extensions again.
- Scheduled anime and manga library updates now persist in the background, even when the app is closed or after the device restarts.
- The default library update interval is 12 hours, with new 6, 8, 12, 24, 48, 72-hour and weekly options.
- Update notifications list titles with new content first, followed by skipped titles and finally update errors.
- Home now includes a new releases tray grouped into `Today`, `Yesterday`, and `This week`, with direct access to watch or read.
- Pending extensions can be processed with `Update all` while preserving user confirmation and signature verification.
- New bugs were added to be fixed in later versions.
