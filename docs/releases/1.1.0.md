## es

### Kitsu X 1.1.0 — cambios desde 1.0.7

Esta actualización corrige el error al abrir fuentes de manga, reorganiza la navegación y reduce las esperas al iniciar y explorar.

### Interfaz y navegación

- Rediseñados Inicio, las bibliotecas y las fichas de anime y manga, con progreso integrado en las portadas, categorías más legibles y filtros rápidos.
- Explorar ahora separa Descubrir, Buscar, Extensiones y Migraciones. Buscar incorpora un selector Anime/Manga y acceso directo a fuentes instaladas; Extensiones y Migraciones usan grupos desplegables y listas a pantalla completa.
- Añadido Recientes a la barra inferior con reloj animado, selector Anime/Manga, vistas Nuevos, Historial, Todos y Agrupados, y búsqueda en cada vista.
- Renovada la barra inferior flotante y eliminada la franja negra detrás del menú.
- Unificada la paleta de la app y retirado el selector de colores. Actualizada la guía de bienvenida para estos cambios.

### Rendimiento

- Eliminada una espera innecesaria al arrancar y reducidas las consultas y el trabajo de Inicio en el hilo de interfaz.
- Descubrir reutiliza los resultados guardados y actualiza temporada, próximos estrenos y tendencias por separado; incorpora un proveedor de respaldo ante fallos del principal.
- Las búsquedas cancelan solicitudes anteriores y permiten reintentar una fuente sin perder los resultados de las demás.

### Correcciones y descargas

- Corregido el error `IllegalStateException: ignoreGzipInterceptor` al abrir extensiones de manga (issue #1).
- Corregida la visualización de capítulos decimales: `0.01` ya no aparece como una cadena larga de dígitos en Inicio.
- Añadidos mensajes claros para errores de almacenamiento, detalle copiable del fallo y reintento individual de descargas.
- Añadida recuperación de imágenes rechazadas por falta de cabecera Referer en fuentes compatibles.

### Cambio de distribución

- Desde esta versión se distribuye únicamente el APK **arm64-v8a**. Se requiere un sistema Android ARM de 64 bits; se dejan de ofrecer las variantes universal, ARM de 32 bits y x86/x86_64.

## en

### Kitsu X 1.1.0 — changes since 1.0.7

This update fixes the error when opening manga sources, reorganizes navigation, and reduces startup and discovery delays.

### Interface and navigation

- Redesigned Home, libraries, and anime/manga detail pages with progress integrated into covers, clearer categories, and quick filters.
- Explore now separates Discover, Search, Extensions, and Migrations. Search adds an Anime/Manga selector and direct access to installed sources; Extensions and Migrations use collapsible groups and full-screen lists.
- Added Recents to the bottom bar with an animated clock, an Anime/Manga selector, New, History, All, and Grouped views, and search within each view.
- Updated the floating bottom bar and removed the black strip behind it.
- Unified the app palette and removed the color selector. Updated onboarding to reflect these changes.

### Performance

- Removed an unnecessary startup delay and reduced Home queries and work on the UI thread.
- Discover reuses cached results and refreshes the current season, upcoming releases, and trending sections separately; a fallback provider handles failures of the primary provider.
- Searches cancel previous requests and allow retrying one source without losing results from other sources.

### Fixes and downloads

- Fixed `IllegalStateException: ignoreGzipInterceptor` when opening manga extensions (issue #1).
- Fixed decimal chapter labels: `0.01` no longer appears as a long string of digits on Home.
- Added clear storage error messages, copyable error details, and individual download retries.
- Added recovery for images rejected because of a missing Referer header in compatible sources.

### Distribution change

- Starting with this version, only the **arm64-v8a** APK is distributed. An ARM 64-bit Android system is required; universal, ARM 32-bit, and x86/x86_64 builds are no longer provided.
