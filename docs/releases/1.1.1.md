## es

### Kitsu X 1.1.1 — cambios desde 1.1.0

Esta versión recupera la distribución para arquitecturas anteriores y mejora la respuesta de la biblioteca, la búsqueda y la reproducción.

### Compatibilidad restaurada

- Vuelven los APK para **ARM de 32 bits (armeabi-v7a), ARM de 64 bits (arm64-v8a), x86 y x86_64**, además de un **APK universal**. Responde al reporte [#4](https://github.com/richtunic/Kitsu-X/issues/4).
- Se mantiene **Android 8.0 o superior**. La arquitectura corresponde al sistema Android instalado, no solo al procesador; si tienes dudas, usa el APK universal.
- Se conserva la firma de las versiones anteriores para actualizar sin desinstalar ni borrar los datos.

### Biblioteca, búsqueda y diseño

- En modo de organización automática, agregar una obra guarda primero su estado en biblioteca; la sugerencia de categoría vía Jikan se obtiene después, con espera limitada. Se mantienen los modos manuales y solo se utilizan categorías ya existentes.
- El selector Anime/Manga de Buscar muestra una marca de selección y el campo indica explícitamente qué tipo se está buscando.
- La navegación lateral de pantallas amplias adopta una barra flotante vertical, coherente con el diseño de la barra inferior, con espacio reservado para el contenido.

### Reproducción de anime

- La selección automática puede iniciar con un candidato disponible sin esperar a todos los servidores; conserva prioridad para la elección manual.
- Se limita la espera de carga por servidor y resolución del enlace para permitir probar alternativas. El servidor, la extensión y la conexión siguen influyendo en el tiempo de inicio; los enlaces rechazados con 403 pueden seguir fallando.
- Las pruebas físicas de una muestra de AnimeAv1 y AnimeOnline.Ninja confirmaron reproducción real. Esto no garantiza funcionamiento o calidad idénticos para todos los episodios y servidores.

### Archivos

Elige el APK de tu arquitectura o el universal. Los hashes de integridad están en `SHA256SUMS.txt`.

## en

### Kitsu X 1.1.1 — changes since 1.1.0

This release restores distribution for older architectures and improves library, search, and playback responsiveness.

### Restored compatibility

- **32-bit ARM (armeabi-v7a), 64-bit ARM (arm64-v8a), x86, and x86_64 APKs** are available again, alongside a **universal APK**, addressing report [#4](https://github.com/richtunic/Kitsu-X/issues/4).
- **Android 8.0 or higher** is still required. Choose the architecture of the installed Android system, not just the processor; use the universal APK if unsure.
- The existing signing certificate is retained so you can update without uninstalling or clearing data.

### Library, search, and design

- Automatic organization saves the library entry before requesting a Jikan category suggestion, with a bounded network wait. Manual modes are preserved and suggestions only use existing categories.
- Search has an explicit Anime/Manga selection mark and a field label indicating the selected media type.
- Wide layouts now use a floating vertical navigation bar consistent with the bottom bar, while reserving space for content.

### Anime playback

- Automatic selection can start with an available candidate while other servers are still loading; explicit manual selection keeps priority.
- Per-server loading and link resolution have bounded waits so alternatives can be tried. Server, extension, and network behavior still affect startup; links rejected with HTTP 403 may continue to fail.
- A physical-device sample confirmed actual playback with AnimeAv1 and AnimeOnline.Ninja. This does not guarantee identical availability or quality across episodes and servers.

### Files

Choose your architecture-specific APK or the universal APK. Integrity hashes are provided in `SHA256SUMS.txt`.
